## 15. Blacklisted Applications Policy

To protect company assets and maintain cybersecurity, the installation or use of blacklisted software is strictly prohibited.

### 15.1 Definition

**Blacklisted applications** refer to any software that:

- Is known to carry malware, spyware, or adware
- Bypasses corporate network security (e.g., unauthorized VPNs, proxies, remote desktop tools)
- Is used for pirating, torrenting, or hacking
- Violates software licensing or copyright laws
- Enables cryptocurrency mining or unauthorized background processing
- Has been explicitly restricted by the IT department

### 15.2 Prohibited Categories

Examples of restricted categories include (but are not limited to):

- Peer-to-peer (P2P) file-sharing tools (e.g., BitTorrent, uTorrent)
- Unlicensed software cracks or keygens
- Personal cloud sync services (e.g., Dropbox, Mega) without approval
- Messaging apps not authorized by IT (e.g., WhatsApp Desktop, Telegram)
- Unapproved developer environments or interpreters (e.g., Node.js, Python, etc., unless approved)

### 15.3 Detection and Enforcement

- Company systems are regularly scanned for unauthorized software.
- Any blacklisted application found will be removed immediately.
- Users will be notified and may be required to explain the reason for installation.

### 15.4 Disciplinary Action

Violations may lead to:

- Written warnings
- Revocation of device or network access
- Internal audits of device activity
- Suspension or termination (for repeated or severe offenses)

### 15.5 Exceptions

Employees may request exceptions by submitting a **Software Use Request** form to the IT department. Approval must be granted before installation.

## 16. Whitelisted Applications Policy

To support work productivity while maintaining security standards, only applications from the approved whitelist may be installed and used on company devices unless otherwise authorized.

### 16.1 Definition

**Whitelisted applications** are those verified, secure, and approved by the IT department for use within the company.

### 16.2 Approved Software List

The following applications are permitted by default:

#### ✅ Productivity & Communication
- Microsoft Office (Word, Excel, Outlook, PowerPoint)
- Google Workspace (Docs, Sheets, Gmail, Drive)
- Slack (Enterprise edition)
- Zoom / Microsoft Teams
- Notion / Confluence / Trello / Jira

#### ✅ Development Tools
- Visual Studio Code / Visual Studio
- IntelliJ IDEA / PyCharm / WebStorm
- Git, GitHub Desktop / GitKraken
- Postman / Insomnia
- Docker / Docker Compose
- Node.js (only with team lead approval)
- Python (only with team lead approval)

#### ✅ Security & Utilities
- 1Password / Bitwarden
- Windows Defender / CrowdStrike
- OpenVPN / AnyConnect (IT-managed)
- WinRAR / 7-Zip
- PDF Readers: Adobe Acrobat Reader / Foxit Reader

### 16.3 Installation Process

- Employees may install apps from the whitelist without additional approval.
- Apps not on the list must go through a **Software Use Request** workflow for evaluation by IT.

### 16.4 Regular Review

- The whitelist will be reviewed quarterly.
- Suggestions for additions can be submitted to the IT Security Team.
